## 한 줄 요약

금융 홍보물의 준법심의를 돕는 AI 에이전트. 게시 시기나 표현 때문에 논란이 될 광고를 짚는 사회맥락 리스크 검토를 새로 붙이고, 3분을 넘기던 AI 분석 시간을 줄임

- **서비스** · 홍보물·약관·상품설명서 업로드, OCR, 법령·사내 심의기준·과거 심의 사례 근거 검색, 전문 에이전트 동시 검토, 준법심의자 최종 판단, 심의필 발급
- **담당** · 사회맥락 리스크 에이전트 · 사회맥락 규칙 엔진 · 근거 검색과 OCR 보강 · AI 분석 속도 개선 · 제품 브리프
- **스택** · TypeScript · Next.js · PostgreSQL (pgvector) · Prisma · Claude API
- **저장소** · [jb-finproof-team/FinProof](https://github.com/jb-finproof-team/FinProof) · 올린 PR #2, #3, #11, #25

### 1. AI가 확정하지 못하던 사회맥락 판단을 규칙 엔진으로 · PR #2, #3, #11

- **문제** ‘침몰하는 금리 시장’처럼 법에 걸리는 말은 없어도 참사를 떠올리게 할 수 있는 문구. 처음에는 이 판단을 생성형 AI에 맡겼더니, 사회맥락과 상관없는 일반 준법 이슈에도 ‘사회맥락’ 배지가 붙음
- **첫 수정** 승인된 사회맥락 지식 문서를 근거로 인용한 이슈에만 배지를 달고, 근거를 못 찾은 판단은 이슈로 남기지 않음
- **남은 문제** 시스템이 4월 16일이 어떤 날인지, 그 문구가 어떤 참사와 이어지는지 스스로 확정하지 못함. 이 한계는 PR에 그대로 적어 공유
- **해결** 민감한 사건의 날짜와 그 사건을 떠올리게 하는 표현, 상징을 이어 둔 지식 그래프 데이터를 읽어 판정하는 규칙 엔진 작성
  - 게시 예정일이 사건 날짜에서 정해 둔 범위 안에 드는지, 문구에 그 표현과 금융 혜택 문구가 함께 있는지 규칙으로 판정
  - 걸린 날짜, 사건, 표현, 규칙을 차례로 적어 근거로 붙이고, 엔진 결과는 다른 에이전트의 종합 판단에도 근거로 전달
  - 위험으로 나와도 반려하지 않고 보류로 넘겨 심의자가 결정
- **결과** 같은 광고에는 늘 같은 판정. 아래 경우를 테스트로 고정
  - 세월호 참사일에 ‘금리 침몰급 혜택’을 내건 적금 광고는 위험, 비슷한 문구라도 다른 날이면 주의
  - 5월 18일에 ‘탱크데이’를 내건 카드 혜택 광고는 위험, 세월호 참사일의 추모 기부 안내는 참고
  - ‘Fish Tank’처럼 안전한 문맥에 쓰인 Tank는 무시
- **남은 것** 데이터에 함께 든 검증용 사례를 엔진에 모두 돌려 맞춰 보는 테스트는 만들지 못함

### 2. 3분을 넘기던 AI 분석 시간 줄이기 · PR #25

- **문제** AI 분석이 한 건에 3분 넘게 걸림. 심의 대기 화면은 2초 간격으로 90번만 분석 상태를 확인하고, 그 뒤에는 분석이 아직 돌고 있어도 실패로 표시
- **해결**
  - 전문 에이전트마다 우선순위가 높은 이슈 3개까지만 넘기고, 근거 검증은 8건, 종합 판단은 10건만 자세히 넘기고 나머지는 요약. LLM 재검증은 6건까지로 묶음
  - 표현, 상품 조건, 사회맥락 검토는 Claude Haiku에, 법규 검토와 종합 판단, 근거 검증은 Claude Sonnet에 배분
  - 화면의 3분 제한을 없애 오래 걸린 분석도 끝나면 결과가 뜨게 함
- **결과** 같은 계열 테스트 케이스가 약 2분 55초에 끝나 3분 안으로 들어옴 (로컬 측정)

## 기술 선택 이유

| 선택 | 이유 |
| :-- | :-- |
| 사회맥락 판정은 규칙 엔진으로 | 무엇이 민감한 표현인지는 정답이 없어서, 기준이라도 눈에 보이게 하려고. 같은 광고에 같은 판정이 나오고 어떤 사건과 표현이 이어졌는지 경로가 남음 |
| 위험 판정도 보류로 | AI를 최종 승인자로 두지 않는 것이 서비스 원칙. 최종 판단은 준법심의자가 함 |
| 모델 나눠 쓰기 | 가벼운 판단은 빠른 모델(Claude Haiku)이 맡아 전체 분석 시간을 줄이고, 법규와 종합 판단은 Claude Sonnet이 맡음 |
